Technician's Final Verdict

DO NOT CLOSE UNTIL RESOLVED

This vehicle has an unresolved high-voltage drive system fault tied directly to recent dealer service, and cannot currently pass a California smog check.

What We Found

Scanned with a professional bidirectional scan tool: one stored code, marked PERMANENT — P0C17, "Drive Motor 'A' Position Sensor Not Learned."

A permanent code is built to survive a code-clear or battery reset. It only turns off once the car itself confirms, through real driving, that the fault is actually fixed. Whoever reset this vehicle's codes could not make this one disappear.

The #1 documented cause of this exact code: recent high-voltage battery service or a module reset that was never finished with the required motor/resolver calibration relearn — a procedure that needs a dealer-level scan tool, not a basic code reader.

Because that relearn was never completed, the readiness monitors are not set. The car will fail California smog as it sits right now.

How This Ties to the Dealer

[Dealer]'s own service record (RO #[Redacted], 9/22/26, inspector [Redacted]) shows real work was done on this car that week — $1,160.48 approved, $175.40 declined.

Field notes taken during the scan point the same direction: battery-related codes had been cleared, and a motor position sensor code could not be cleared because it takes dealer-level tooling to reset — consistent with a battery-system reset that was started and not finished.

Steering Noise — Separate, Minor Issue

Not the main issue here. The dealer's own inspection already logged this rubbing noise on 9/22 and closed it out with a $0.00 repair estimate — acknowledged, not fixed. Worth a mention, not the headline.

What Needed to Happen Before This Sale Closed

Dealer completes the motor/resolver calibration relearn on their own equipment and clears the permanent code for real, or price is adjusted to reflect a car that currently cannot pass smog and has a documented unresolved hybrid-drive fault.

This is what a real inspection catches — not a walk-around with a flashlight.
